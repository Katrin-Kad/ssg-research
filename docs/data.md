# Данные

Набор данных содержит 200 измерений времени отклика сервиса при разной нагрузке. Каждое измерение повторялось пять раз, чтобы оценить погрешность.

| Поле | Описание |
|---|---|
| `load` | Нагрузка, запросов в секунду |
| `latency_ms` | Время отклика, мс |
| `run_id` | Номер запуска |

Версия набора данных: **2026-10-01**. Описание процедуры обработки приведено в разделе [Методика](method.md#calc).
