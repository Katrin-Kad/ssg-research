# Результаты эксперимента

Учебный сайт: здесь опубликованы данные, методика и результаты эксперимента по оценке зависимости времени отклика сервиса от нагрузки.

Версия сайта выбирается в шапке страницы (переключатель справа от названия). Адрес `latest` всегда ведёт на самую свежую версию.

- [Данные](data.md) — откуда взяты измерения
- [Методика](method.md) — как проводился расчёт
- [Результаты](results.md) — итоговые значения

!!! note "Как цитировать"
    Используйте файл `CITATION.cff` в репозитории или DOI на Zenodo (после создания релиза).
